# Barbearia Fiais
Sistema de gerenciamento para barbearias desenvolvido em Python utilizando Flask.

## Funcionalidades
- Login de administrador
- Login de clientes
- Cadastro de clientes
- Cadastro de serviços
- Agendamento de horários
- Cancelamento e edição de agendamentos
- Histórico de atendimentos
- Dashboard administrativo
- Controle financeiro
- Fechamento mensal
- Histórico financeiro

## Tecnologias
- Python
- Flask
- SQLAlchemy
- SQLite
- Bootstrap 5
- HTML5
- CSS3
- JavaScript

## Instalação
```bash
git clone <repositorio>
cd barbershop-system
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python run.py
```
